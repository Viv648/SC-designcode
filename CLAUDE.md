# SC: Designing in Code — AI Context

This is a Skyscanner internal training repo. People working through these exercises are learning how to translate designs into code — many come from non-engineering backgrounds (design, product, etc.).

## What this repo teaches

- Writing HTML and CSS to match a design brief
- Extracting reusable component patterns
- Using CSS custom properties (design tokens) instead of hard-coded values

## Repo layout

```
exercises/
  01-intro/         starter/ + solution/   — first HTML page
  02-components/    starter/ + solution/   — card list with reusable markup
  03-design-tokens/ starter/ + solution/   — CSS variables / tokens
resources/
  cheatsheet.md     — quick HTML/CSS reference
  links.md          — useful docs
```

## How to help people in these exercises

- They are editing files in the `starter/` folder of each exercise.
- The goal is always to make the page match the brief in that exercise's README.
- Keep changes minimal and focused — don't refactor things beyond the task.
- Explain what you're doing in plain English, not jargon.
- If they ask "what does this do?", explain it simply.
- If they ask you to make a change, make it directly in the file they mention.
- Skyscanner brand colour: `#0770e3` (blue).

## Tone when helping

- Friendly and encouraging — learners may be nervous about touching code.
- Short explanations. No walls of text.
- Show the change first, then explain it in one or two sentences.
