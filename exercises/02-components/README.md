# Exercise 2: Components

Break a UI into reusable pieces.

## Goal

Refactor the starter file so repeated UI is extracted into a reusable component pattern.

## Brief

The starter file has a list of cards with duplicated markup. Your job is to:
1. Identify the repeated pattern
2. Refactor it (using a function, template, or component depending on your stack)
3. Make it easy to add a new card with minimal code

## Steps

1. Open `starter/` in your editor
2. Spot the duplication
3. Refactor and test — the page should look the same when you're done

## Done?

Compare your approach against `solution/`.
