# Exercise 2: Components

Break a UI into reusable pieces.

## Goal

The starter file has a list of cards with duplicated markup. Refactor it so you can add a new card with minimal effort.

## Brief

1. Spot the repeated pattern in the starter file
2. Refactor the markup to reduce repetition
3. Add a new card — it should be easy to do now
4. The page should look the same when you're done

---

## Option A — Do it yourself

1. Open `starter/` in your editor
2. Look for sections that are copy-pasted
3. Refactor and test

## Option B — Use AI (Claude)

Open a terminal, type `claude`, then try:

```
Look at exercises/02-components/starter/ and explain what's repeated
```

```
Refactor the cards so the markup isn't duplicated — keep the page looking the same
```

```
Add a new card with the title "Singapore" and the description "Hawker food paradise"
```

```
Make the cards sit side by side on wider screens
```

After each step, open the page in your browser and check nothing broke.

---

## Done?

Compare your approach against `solution/`. Your solution might look different — what matters is that adding a new card is now easy.
