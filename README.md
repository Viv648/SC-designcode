# SC: Designing in Code

Internal Skyscanner training — hands-on exercises for building UIs in code.

## What you'll learn

- How to translate designs into code
- Working with components and design tokens
- Building consistent, scalable UI

## Getting started

1. **Clone the repo**
   ```bash
   git clone https://github.com/choon00o/SC-designing-in-code.git
   cd SC-designing-in-code
   ```

2. **Follow the setup guide**
   See [SETUP.md](./SETUP.md) for prerequisites and local setup.

3. **Work through the exercises**
   Each exercise is in `exercises/` — start with `01-intro` and follow the `README.md` inside.

## Repo structure

```
exercises/
  01-intro/         # Exercise 1
  02-components/    # Exercise 2
  03-design-tokens/ # Exercise 3
resources/
  cheatsheet.md     # Quick reference
  links.md          # Useful docs & tools
```

## During the session

- Work in the `starter/` folder of each exercise
- The `solution/` folder is there if you get stuck — try not to peek too early!
- Ask questions any time
