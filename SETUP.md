# Setup Guide

Follow these steps before the training session starts.

## Prerequisites

- [Node.js](https://nodejs.org/) v18 or later
- [Git](https://git-scm.com/)
- A code editor — [VS Code](https://code.visualstudio.com/) recommended

## Check your setup

Run these in your terminal to confirm everything is installed:

```bash
node --version   # should print v18 or higher
git --version    # should print a version number
```

## Clone the repo

```bash
git clone https://github.com/choon00o/SC-designing-in-code.git
cd SC-designing-in-code
```

## You're ready

Open the folder in your editor and head to `exercises/01-intro/README.md` to begin.
