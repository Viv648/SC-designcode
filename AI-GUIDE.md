# Using AI (Claude) in These Exercises

You don't need to know how to code. Just describe what you want and Claude will make the change.

---

## How to start

1. Open the file you want to change in VS Code
2. Press `` Ctrl+` `` (Windows) or `` Cmd+` `` (Mac) to open the terminal
3. Type `claude` and press Enter
4. Type what you want — in plain English

---

## Tips

**Be specific about the file:**
> "In exercises/01-intro/starter/index.html, make the background pink"

**Describe what you see vs what you want:**
> "The button is blue. Make it green."

**Ask it to explain:**
> "What does padding do?"

**If something looks wrong:**
> "That broke the layout — can you undo it and try differently?"

---

## You're in control

Claude writes the code. You decide if you like the result. If you don't, just say so and ask it to try again.
